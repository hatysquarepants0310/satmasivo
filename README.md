# SAT Masivo

Mismo programa en Ubuntu (`.deb`) y Windows (`.exe`).

1. Home: RFC + CIEC + captcha.
2. Recibidas / Emitidas.
3. Descargar. *Reporte* = último lote. *Reporte de carpeta* = otra carpeta.

```bash
# Ubuntu
sudo apt install ./satmasivo_1.4.0_all.deb
satmasivo
```

Windows: corre `satmasivo.exe` del release. No instala Python.
